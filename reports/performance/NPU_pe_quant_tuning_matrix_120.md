# [검증] qbcompiler 1.2.0 양자화×튜닝 매트릭스 24종 — NPU 실측

GPU 서버에서 1.2.0으로 컴파일한 24조합을 NPU 서버에서 정확도·채널 지연으로 채점한 결과.
1.1.2 매트릭스([`NPU_pe_quant_tuning_verify.md`](NPU_pe_quant_tuning_verify.md))의 후속이며,
**버전 원인 규명은 [`NPU_pe_quant_tuning_compiler_version.md`](NPU_pe_quant_tuning_compiler_version.md)**.

## 1. 결론

1. **튜닝(OPTQ+SWS)이 3개 양자화 모두에서 정확도를 올린다.** 1.1.2에서 전부 떨어뜨렸던 것과 정반대다.
2. **코어모드는 정확도에 영향이 없다.** 같은 양자화·튜닝이면 4모드 cos가 소수 4자리까지 동일하다.
   코어모드는 지연 특성만 바꾼다.
3. **W8A16 + 튜닝(0.9946)이 현행 배포본(0.9937)보다 정확하다.** 크기·속도는 동일 → 사실상 공짜 교체.
4. **W4A8 + A16×5 + 튜닝이 0.9420**으로, 크기 −42%면서 가장 빠르다(20ch 19.94 img/s).
   튜닝 없는 W4A16(0.9175)보다 정확하면서 더 빠르다.

- `global8` 은 이 측정 구간에서 뚜렷한 이점이 없다.

## 5. ★ 이전 W4A8 수치(0.8932)는 잘못된 값이었다

[`NPU_pe_quant_tuning_compiler_version.md`](NPU_pe_quant_tuning_compiler_version.md) 에 기록한
W4A8_L5A16 1.2.0 값 **0.8932 는 A16 텐서 5개가 빠진 산출물**이었다. 정정값은 **0.9420**.

- 원인: 그 측정에 쓴 임시 하네스를 `--preset w4a8_l5a16 --optq --sws` 로 호출했는데, 그 하네스는
  A16 텐서를 `--act16` 으로만 받는 구조였다. `--act16` 을 넘기지 않아 **qk16 25개만 16bit**였다.
  컴파일 로그에도 `[qk16] score MatMul 25개` 만 있고 A16 라인이 없다.
- 이번 GPU 매트릭스는 `compile_quant_tuning_matrix.py` 가 `A16_TENSORS_W4A8` 5개를 정확한 mblt
  이름으로 주입한다 → 0.9420.
- **W4A8 계열은 A16 주입 여부를 로그로 반드시 확인할 것.** `[quant] activation16=30`(qk16 25 + A16 5)
  이어야 하며, 25면 A16이 빠진 것이다. 과거 cos 0.2609 오측정도 같은 계열의 문제였다.

정정 후 W4A8 계열의 버전 비교는 아래와 같다(둘 다 A16 정상 주입).

| W4A8 + A16×5 | 튜닝 없음 | +OPTQ+SWS | 튜닝 효과 |
| --- | ---: | ---: | ---: |
| qbcompiler 1.1.2 | 0.8790 | 0.8560 | −0.023 |
| qbcompiler **1.2.0** | 0.8884 | **0.9420** | **+0.054** |

벤더 회신값(0.905)과 비교하면 **1.2.0 실측이 오히려 이를 넘어선다**(0.9420).

## 6. 부수 확인

- **베이스라인의 컴파일러 버전 무관성**이 3개 양자화 전부에서 확인됐다(이전엔 W4A16만).
  W8A16 none: 1.1.2 0.9937 ↔ 1.2.0 0.9937. W4A16 none: 0.9110 ↔ 0.9175. W4A8 none: 0.8790 ↔ 0.8884.
- **컴파일 환경(CPU/GPU) 무관**: W8A16 sws_optq CPU 0.9951 ↔ GPU 0.9946, W4A16 sws_optq CPU 0.9642 ↔ GPU 0.9654.
- **이미지 세트 민감도**: 다른 20장으로 재측정해도 W8A16은 소수 4자리까지 동일, 4bit 계열은 ±0.005 내에서 움직인다.
  회귀 판정 허용오차 ±0.005는 4bit 계열에서 빠듯하므로, 이 리포트의 24점을 표준 세트 기준으로 재앵커링했다
  (`verify_quant_tuning_matrix.py` 의 `BASELINE_120`).
