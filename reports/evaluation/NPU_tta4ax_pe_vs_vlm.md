# TTA_4종_AX 프레임 평가 — PE 1차 vs VLM 2차(벤더 bs32 / 사내 ft) (2026-10-01)

NPU 서버에서 같은 프레임·같은 프롬프트로 세 경로를 돌려 정답과 대조했다.
**정확도 평가**이며, 속도 비교는 `reports/performance/qwen3vl/` 쪽이다.

- 데이터: `eval/datasets/TTA_4종_AX` TC1(falldown)/TC2(fire)/TC3(smoke)
- 재현: `eval/tta4ax/` (프레임 추출 → 요청 → 채점)

---

## 1. 결론

| 항목 | 권장 |
|---|---|
| 2차 모델 | **사내 재컴파일본(ft)** — bs32 대비 전 항목 우세 |
| 입력 크기 | **256×192** (ft 기준). 224×224 대비 정탐 +8 / 오탐 −1 |
| smoke | **2차 생략**(`NPU_PE_2STAGE_VALIDATION_EXCLUDE=smoke`) — PE 단독이 오탐 0에 정탐 31 |

```bash
NPU_PE_2STAGE_VLM_SIZE=256x192
NPU_PE_2STAGE_VALIDATION_EXCLUDE=smoke
MODEL_HF_PREFIX=ft/model          # PIA-SPACE/AX_NPU_VL3_2B_mxq
```

## 2. 방법

카테고리당 **100장(양성 50 + 음성 50)**, 총 300장.

- **양성**: 프레임 라벨 csv 의 1-구간 중 **가장 긴 구간의 가운데** 프레임 → 정답 `yes`
- **음성**: 이벤트가 없으므로 클립 가운데 프레임 → 정답 `no`

이벤트 구간은 361프레임 중 중앙값 340으로 길어, 가운데 프레임은 구간 한복판이다
(적중·놓침 사이에 구간 길이 차이 없음 → 추출 방식이 결과를 좌우하지 않는다).

| 경로 | 구성 |
|---|---|
| PE 1차 | `MXQInferenceFull` + 제품 `dist` 판정(히스토그램 80bin, normal 과의 IoU < 0.3) |
| VLM bs32 | 벤더 배치32 빌드, 카드 1, 포트 8110 |
| VLM ft | 사내 재컴파일본, 카드 2, 포트 8111 |

VLM 은 `/v1/chat/completions` 로 보냈다 — 프롬프트가 레포 `prompts.py` 와 다르기 때문
(`/api/v1/validate` 는 카테고리로 프롬프트가 고정된다).
PE 전처리는 제품과 동일(cv2 INTER_LINEAR 336, mean/std 0.5), 텍스트 특징은
`assets/model/text_features.json`(13,449 × 1024).

TC4(intrusion)는 프롬프트가 없어 제외했다.

**성격이 다르다.** PE 는 재현율형(falldown 재현율 1.000 / 오탐 14), VLM 은 정밀도형
(정밀도 0.95~1.00 / 미탐 56~84). 1차·2차 역할 그대로다.

### 2단계 직렬 (둘 다 yes 여야 알람)

| 카테고리 | 구성 | 알람 | 정탐 | 오탐 | 미탐 | F1 |
|---|---|---:|---:|---:|---:|---:|
| 전체 | PE + bs32 | 66 | 66 | **0** | 84 | 0.611 |
| 전체 | PE + ft | 91 | 90 | **1** | 60 | 0.747 |

2차를 붙이면 **오탐 18 → 1(ft) / 0(bs32)**. 대신 미탐이 22 → 60 으로 는다.
2차 검증이 하는 일이 정확히 이 교환이다.

## 4. 입력 크기 — 224×224 vs 256×192

★ 단일 실행으로는 판단하면 안 된다. 같은 설정이라도 **실행마다 답이 0~4건 바뀐다**
(배치 구성이 매번 달라진다). 그래서 **각 설정을 3회씩** 돌려 중앙값과 범위를 함께 본다.

| 카테고리 | 서버 | 크기 | 정탐 | 오탐 | F1 중앙 |
|---|---|---|---:|---:|---:|
| fire | bs32 | 224×224 | 21 (21~23) | 0 | 0.592 |
| fire | bs32 | 256×192 | 23 | 0 | 0.630 |
| fire | ft | 224×224 | 41 | 0 | 0.901 |
| fire | **ft** | **256×192** | 42 (41~42) | **0** | **0.913** |
| smoke | bs32 | 224×224 | 3 | 0 | 0.113 |
| smoke | bs32 | 256×192 | 4 (3~4) | **1** | 0.145 |
| smoke | ft | 224×224 | 10 | 4 | 0.312 |
| smoke | **ft** | **256×192** | 17 (16~17) | 4 (3~4) | **0.479** |
| falldown | bs32 | 224×224 | 40 | 0 | 0.889 |
| falldown | bs32 | 256×192 | 42 (42~44) | **1 (1~2)** | 0.903 |
| falldown | ft | 224×224 | 45 | 1 | 0.938 |
| falldown | **ft** | **256×192** | 46 (45~46) | **0** | **0.958** |
| **전체** | bs32 | 224×224 | 64 (64~66) | **0** | 0.598 |
| **전체** | bs32 | 256×192 | 69 (68~71) | 2 (2~3) | 0.624 |
| **전체** | ft | 224×224 | 96 | 5 | 0.765 |
| **전체** | **ft** | **256×192** | 104 (103~105) | 4 (3~4) | **0.806** |

**차이가 실행 변동폭 밖이다** — 전체 기준 세 지표 모두 두 설정의 범위가 겹치지 않는다.

| 서버 | 지표 | 224×224 | 256×192 | 판정 |
|---|---|---|---|---|
| ft | 정탐 | 96~96 | 103~105 | 겹치지 않음 |
| ft | 오탐 | 5~5 | 3~4 | 겹치지 않음 |
| ft | F1 | 0.765 | 0.802~0.814 | 겹치지 않음 |
| bs32 | 오탐 | 0~0 | 2~3 | 겹치지 않음 |

→ **ft 는 256×192 가 낫다**(정탐 +8, 오탐 −1). 반대로 **bs32 는 224×224 를 유지**해야 한다 —
256 으로 올리면 오탐 0 이 깨진다(smoke +1, falldown +1~2).

지연은 사실상 같다: 시각토큰 49(224×224) vs 48(256×192), 160~200ms/건.
256×192 는 레터박스 없이 4:3 을 유지하므로 화면비 이득이 공짜다.

★ **W·H 는 32 의 배수**여야 한다(patch 16 × merge 2). 240 은 16 의 배수지만 32 의 배수가
아니라 320×240 을 주면 320×256 으로 조용히 올림된다 → `vlm_pool.py` 가 기동 시 거부한다.

## 5. 우선순위별 권장

우선순위가 **fire 오탐 최소 / falldown 정탐·오탐 둘 다 / smoke 는 오탐만** 일 때:

| 카테고리 | 선택 | 근거 |
|---|---|---|
| fire | **PE + ft (256×192)** | 오탐 0 유지, 정탐 41~42. PE 단독은 오탐 4 |
| falldown | **PE + ft (256×192)** | 오탐 0, 정탐 46. PE 단독은 정탐 50 이지만 오탐 14 |
| smoke | **PE 단독(2차 생략)** | 오탐 0 에 정탐 31. 2차를 붙이면 오탐은 그대로 0 인데 정탐만 8 로 깎인다 |

전부 `PE + ft` 로 통일해도 오탐은 같지만 정탐이 23건 줄어든다(smoke 31 → 8).

## 6. 한계

- **프레임 단위** 평가다. 운영의 클립 단위 판정과 다르다.
- 운영의 **3프레임 연속 조건**(`ALARM_DURATION_THRESHOLD=3`)을 적용하지 않았다.
  PE 단독 오탐(falldown 14, fire 4)은 그 조건에서 더 줄 수 있어 **PE 에 불리하게** 잡힌 값이다.
- PE 는 ROI 없이 전체 프레임을 넣었다(운영은 ROI 크롭 사용).
- 프롬프트는 운영 요청 문안이며 레포 `prompts.py` 와 셋 다 다르다.
- `text_features.json` 에 class 4·6·7 이 없다(주석은 8종, 실제 5종). 이번 3종에는 무관.
