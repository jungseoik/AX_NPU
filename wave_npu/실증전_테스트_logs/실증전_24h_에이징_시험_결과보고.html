오탐 6건은 모델이 해당 자세를 애초에 “쓰러짐”으로 인식한 결과임. 운영과 동일한 학습본 모델·판정 문안·입력 해상도(256×192)로 재현 시험을 수행하고, 동일 입력에 대한 모델의 장면 서술을 추출하여 확인함.

  • 실행 환경: 운영 검증서버와 동일 컨테이너(mblt-model-zoo 2.3.0+tta1 / qbruntime 1.4.0+repack1)
  • 판정 문안: 운영 문안 원문 그대로 적용, 입력 256×192 고정
  • 재현 결과: 1차 후보에 대한 운영 로그의 통과·기각 판정과 전부 일치

판정 로짓의 해석

모델 출력은 확률이 아닌 로짓이며, ‘yes’·‘no’ 두 로짓의 차이만이 판정에 관여함. 로짓은 softmax 이전의 원시 점수로 값의 범위에 제한이 없음. 본 모델은 두 토큰의 로짓만 비교하는 이진 판정 구조이므로, 판정 확률은 두 값의 차이를 로지스틱 함수에 통과시켜 산출함.
판정확률 P(yes) = 1 / (1 + e−(yes로짓 − no로짓)) = sigmoid(여유도)
  • 로짓 절대값(관측 범위 36~45)은 단독으로 의미를 갖지 않음. softmax 는 전체 가산 이동에 불변이므로 두 로짓에 같은 값을 더해도 확률은 변하지 않음
  • 따라서 본 항은 절대값이 아닌 차이(이하 ‘여유도’)를 기재하며, 환산 확률을 병기함
  • 여유도 0 = 확률 50%(판정 경계), +1.1 = 75%, +2.2 = 90%, +4.6 = 99%

  • 정상 기각 건에서는 “똑바로 서 있다(stands straight upright)”, “발 일부만 화면에 보인다(a foot partially visible)”로 정확히 서술함. 모델이 해당 카메라 전체를 오인하는 것이 아니라, 화면 하단에 인물이 크게 걸리거나 바닥에 앉은 경우에 한해 수평 자세로 인식함

  • 특히 카메라 819의 08:45:11 건은 서술 내용이 통과 건과 동일함에도 확률 66.9%로 경계에 위치하여, 동일 장면의 판정이 뒤집히는 원인으로 확인됨
  • 운영 응답에 ‘yes’·‘no’ 로짓이 이미 포함되어 있어 판정확률 임계값(예: 90% 이상만 통과 = 여유도 +2.2) 적용이 기술적으로 가능하나, 현 단계의 조치 대상은 아님(제6항).
